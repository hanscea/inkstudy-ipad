# 研究实施说明

完整研究入口 `InkStudy` 使用协议 `native-research-v3-20260910-0910V2`，兼容已有 `native-research-v2-20260910-untimed` 记录。独立入口 `InkStudyHints` 使用提示协议 `multimodal-preview-v1-20260917`，只开放混色与力度的成人/虚构示例演练。两者使用独立 App 沙盒。

新建预实验沿用同一参与者已有的协议版本；已有 v2 访次继续其原交互和压力试次。用途分为演练和预实验；正式采集尚未开放。所有任务不限时，按事件时间记录用时、暂停、恢复和提前停止。

## 入口与组别

首页的色彩、线条、综合创作模块是演练，记录使用独立的 `DEMO-*` 代号。研究预实验从“新建研究访次”进入，只填参与者代号，不填姓名。

| 组别 | 训练方式 | 测量方式 |
| --- | --- | --- |
| U | 分组前基线，不提供学习提示 | 原生 iPad 独立测量 |
| A | 纸本人工教学，记录教师、作品编号和实施情况 | 与数字组相同的原生 iPad 测量 |
| B | 数字训练，三个固定提示 | 学习提示关闭 |
| C | 数字训练，本地模型从审核提示库中选择文本 | 学习提示关闭 |

专员协助仅限工具位置、撤销重做操作、笔连接、照读文字和暂停恢复，B、C 组执行相同规则。协助开始、结束、类别、专员代号和持续时间单独记录；不能用操作协助追加教学答案。

## 最新提示演练入口

`InkStudyHints` 首页选择 B 或 C、混色或力度，可以载入虚构示例笔迹。该入口不执行完整的 V1a 至 V7 访次。

| 条件 | 策略选择 | 呈现 |
| --- | --- | --- |
| B | 每项预定的三个动作序列 | 本地短句、动作示范、定位圈与普通话朗读 |
| C | 按当前操作建立候选集合，配对并取得成人演练同意后由 DeepSeek 选择；不可用时使用本地候选动作 | 与 B 相同 |

首次提示前至少完成一笔，每项最多三次，间隔至少十五秒；完成尝试后停顿四十五秒可以自动触发提示。绘画开始时隐藏示范覆盖层，覆盖层不进入作品。语音可以停止、重听，播放状态单独记录。

混色证据来自实际落入调色盘的颜料量、混合区域和配比方差；力度证据来自有效 Pencil 样本、相对目标的带符号误差和离散度。当前阈值属于工程设置，尚未用儿童样本标定。

提示服务只接收任务、目标、笔画数和白名单数值摘要。模型只能返回候选动作编号，实际中文句子与动画保存在本地。调用来源、模型标识、请求 UUID、延迟和回退原因进入 `hints.csv`；`hint-delivery.csv` 记录显示及语音生命周期。语音播放完成只表示播放过程结束。

这一预览协议不改变完整研究入口的既有本地 C 组逻辑，也不自动启用儿童预实验的云端提示。

## 活动规则

色彩练习使用大红 `#FF0000`、柠檬黄 `#FFFF00`、湖蓝 `#0000FF`、橙 `#FFA500`、绿 `#00FF00`、紫 `#800080`。混色目标自动配对：橙色对应红黄、绿色对应黄蓝、紫色对应红蓝。配对回答记录的是预设组合，不能作为儿童自主选色的学习证据。三种目标均尝试过即可继续，不按答对率筛掉儿童。色环按相邻关系判断，整体旋转和反向摆放均可成立。

新混色画纸使用 `standard-palette-v4`、`standard-rgb-v1-20260911`。每次蘸色产生独立颜料批次，后续笔画消耗有限余量；余量耗尽后只搅拌，再点颜色才补充。颜料质量在局部转移中守恒，颜色由实际比例决定，不以后一笔覆盖前一笔。换目标或新纸不删除旧笔迹。

每张画纸的 `background.pigmentModel`、调色板版本、App 版本和原始笔刷 RGB 决定回放条件。旧画纸继续采用其已记录的模型；无模型字段的旧纸使用 `ryb-pigment-v1`。分析时应区分这些模型和条件，原始采样与修正事件均保留。

训练上色可在小猫、小狗、小鸟、花朵、树木、小草中选线稿。测量保留固定 A/B/C 题本线稿和 14 道色彩题，首次作答写入后不覆盖，也不显示答案反馈。

研究线条使用墨色 `#24312b`：压力与路径任务的笔刷参数固定为 80，设备检查和情境线条为 28。线条训练使用明显的压感粗细变化；压力引导线使用同一映射显示目标粗细。压力与路径测量采用固定显示宽度，避免把实时表现反馈带进测量；原始压力仍完整采样。情境线条训练使用简短故事和多种可选画法，不建立“某种情绪只有一种正确线条”的评分规则。

当前压力训练共六条：轻、中、较重、从细到粗、从粗到细、细到粗再到细。后三条的边框轮廓与位置目标一同变化，压力误差按采样位置对应的目标计算。测量使用六条稳定目标试次，保持既定顺序与固定显示宽度；旧协议训练保留原试次。上色线稿始终显示在颜色笔迹上方，导出也采用这一图层顺序。

控制线条抬笔后自动保存，测量固定每个试次的首次技术有效笔迹，不替换成随后画得更好的结果。训练可以反复重画，每次独立画纸和记录都保留。开放绘画支持撤销、重做，完成时点击“保存这次绘画”，再进入下一项。失败或中断的尝试也导出。

技术有效性依据采样是否可用：预实验至少 20 个已解决估计属性的 Pencil 接触采样；演练至少 2 个采样，允许手指预览。压力准确度和路径覆盖率不是进入下一项的门槛。设备检查还要求收到变化的压力信号。中断笔迹或尚未解决的估计属性不作为已完成控制试次。

## 压力与模型版本

压力保留 UIKit 的 `force` 和 `maximumPossibleForce`，归一化值为二者之比。当前轻、中、较重练习目标为 0.15、0.30、0.50，版本 `native-force-targets-v1-pilot`。这组目标需要本设备与目标儿童群体的预实验标定，不能直接与网页旧目标的误差数值合并比较。

完整研究入口的 C 组执行本地 softmax 模型推理，记录 12 个输入特征、概率、选定类别、模型 ID、权重指纹和提示 ID。模型训练来源是合成任务遥测，`fieldValidated=false`。低置信度、模型不可用或任务领域不匹配时回退到 B 组固定提示，并记录回退原因。独立提示演练使用前述候选动作与云端选择规则。

B、C 组采用相同的提示时机与数量限制：首次独立尝试后可主动求助；连续两次不匹配时或尝试后连续 45 秒无操作时可触发提示；每项最多 3 次，间隔至少 15 秒。45 秒只用于提示触发，不会结束任务。压力偏离触发暂用 MAE > 0.12，路径偏离暂用归一化偏离 > 0.035，这些预实验阈值随协议版本记录。正式冻结前须验证模型、阈值、题本、评分流程与现场操作，并完成相应研究审批。

完整研究入口的普通话朗读由儿童或专员点击触发。学习提示仅朗读本项已显示的原文；独立测量仅朗读题目或操作说明。朗读请求单独记录文本、任务、提示 ID、系统语音 ID 与请求时间，不计为新尝试或新增提示。记录的是请求，不等同于完整听完；旧协议不新增朗读干预。独立提示演练在显示动作提示时自动朗读，并另记播放生命周期。

## 保存与导出

原始绘画保存在 `Documents/InkStudy/drawings.sqlite`，访次事件保存在 `Documents/InkStudy/Research/`。进入画纸前先保存关联编号，即使中断发生在两个存储之间，重开也能恢复同一关联。研究画纸不进入自由画纸的可编辑列表。

研究 ZIP 中的 `study.json` 是完整访次事件，`summary.csv` 是各项起止及草稿，`responses.csv` 是作答，`trials.csv` 是尝试与首次有效选择，`operator-help.csv` 是专员协助，`narration.csv` 是朗读请求；每个 `drawings/<UUID>/` 包含 PNG、原始 JSON、采样 CSV 和画纸 manifest。根 manifest 列出原协议版本、当前渲染器版本、所有文件哈希及缺失关联，不把不完整导出标成完整。

保存失败时停止操作，先重试保存；不要卸载 App 或清理应用数据。CSV 对可能被表格软件执行的前导符号作转义，原文完整保留在 JSON 中。万相只在独立体验或所有研究测量完成后使用；其生成图和调用记录存放在单独目录，不进入儿童原画评分。
